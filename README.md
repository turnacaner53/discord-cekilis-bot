# Discord Çekiliş Botu

Discord sunucunuzda çekiliş düzenlemenizi sağlayan basit bir bot.

`/cekilis` komutuyla kişileri ve kazanan sayısını seçin. Kazananlar kanalda herkese açık olarak paylaşılır.

## Kurulum

1. Proje bağımlılıklarını yükleyin:

   ```bash
   npm install
   ```

2. Discord bot token'ınızı `.env` dosyasına ekleyin.
3. Botu sunucunuza ekleyin.

## Çalıştırma

```bash
npm start
```
